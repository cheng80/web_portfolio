# Unity 포트폴리오 구성 기준

Unity 전반의 클라이언트 개발 경험을 첫 화면과 첫 8장에 집중한다. 교육 콘텐츠뿐 아니라 Unity 게임의 제작과 라이브서비스, AR 인식, 외부 장치 연동을 각각 근거로 보여준다.

- 웹: 소개 → Unity 역량 → 회사 콘텐츠 → 우주좀비 → 하드웨어 → 경력 → Flutter 게임 → AI 활용 개발 → 개인 앱 → AI/RAG → 아카이브.
- 슬라이드: 23장, 16:9. 앞 8장은 Unity 중심, 뒤 15장은 최근 개발과 이전 작업이다.
- 네이비, 오프화이트와 기존 타이포그래피를 유지한다. 기존 컴포넌트를 재사용하고, 우주좀비는 원본 PDF에서 추출한 단독 이미지로 제시한다.
- 웹은 모바일에서 한 열로 읽히게 한다. 한국어 제목과 설명은 어절 단위로 줄바꿈한다.
- 슬라이드 배치는 페이지 번호에 종속되지 않게 프로젝트별 CSS 클래스를 사용한다.
- 모든 제목과 본문은 HTML 텍스트다. 이미지로 본문이나 전체 슬라이드를 대체하지 않는다.
- 총 경력 13년 4개월은 최신 이력서 기준이다. Unity 경력의 연수로 바꾸지 않는다.
- Unity와 Flutter/Flame의 게임 구현 경험을 기술별로 구분한다. 세부 사실은 docs/CONTENT_SOURCES.md를 따른다.

우주좀비는 2015년의 이전 Unity 작업으로 회사 콘텐츠 다음, 하드웨어 연동 바로 앞에 둔다.
