## 이미지

우주좀비 이미지는 원본 포트폴리오 23쪽의 `X99.jpg`(896×1006)를 변형 없이 추출했다. 같은 페이지의 Touch 바이블은 Lua 프로젝트이므로 Unity 사례 이미지와 분리했다.

기존 앱, 회사 콘텐츠, 하드웨어 화면은 프론트엔드 버전의 자료를 복사했다. Stone Match 두 번째 화면은 Ego Lite에서 타이머와 애니메이션 시점을 고정한 디버그 픽스처 촬영본이며, 성과나 성능 측정 자료로 사용하지 않는다.

## 표시 원칙

확인된 사실을 재배치하고 표현을 정리했다. 총 경력과 특정 기술의 경력을 구분하고, 출시 상태와 과거 서비스 기간을 유지한다. 기술이나 담당 범위를 새로 주장할 때는 원본 근거를 함께 확인한다.

## 문구 검토

2026-11-04에 Claude Opus 5.5 (`claude-opus-5-5`), `high` 설정으로 웹, 19장 슬라이드, 두 버전 안내 화면과 참고 JSON을 전수 검토했다. 실제 응답의 `modelUsage`에서 모델을 확인했고, 75개 수정안을 원본 자료와 대조해 반영했다. 경력 합계, 앱별 출시 상태, 프로젝트명과 기술 표기를 맞추고 역량 소개를 Unity, 프론트엔드, 백엔드, 하드웨어 범위로 정리했다.

원본 포트폴리오의 하드웨어 항목에는 Unity가 Mosquitto 브로커를 통해 ESP32 센서 정보를 받고 LED를 제어하는 내용이 있다. Arduino 시리얼 통신과 MQTT-SSL 프로젝트의 연결 방식을 구분해 설명한다.

같은 모델과 설정으로 23개 후속 수정안도 검토했다. 일반 소개의 범위를 Unity 게임과 인터랙티브 콘텐츠 전반으로 넓히고, 가운뎃점을 쉼표나 조사로 바꿨다. 2D 표기는 우주좀비의 개별 구현 사실에만 남겼다.
